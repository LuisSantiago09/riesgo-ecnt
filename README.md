# Predicción del riesgo de ECNT

## Descripción
Proyecto de aula de Inteligencia Artificial de Ingeniería de Sistemas, orientado a explorar la relación entre los determinantes sociales de la salud y el riesgo de enfermedades crónicas no transmisibles (ECNT) en población dispersa.

## Problema
Las condiciones de acceso al agua potable, el saneamiento básico y la educación pueden relacionarse con las condiciones de salud de las poblaciones rurales y dispersas. El proyecto busca explorar el uso de técnicas de aprendizaje automático para analizar esta relación.

## Objetivo
Explorar la viabilidad de construir un modelo de Inteligencia Artificial que estime un indicador asociado al riesgo de ECNT a partir de variables sociales y demográficas disponibles.

## Tecnologías
- Python
- Google Colab / Jupyter Notebook
- Pandas y NumPy
- Matplotlib y Seaborn
- Scikit-learn

## Modelos propuestos
- Regresión lineal múltiple como modelo base.
- Gradient Boosting como modelo propuesto.

## Fuentes de datos
Se consideran inicialmente fuentes como DANE, NBI, ENSIN y RIPS. La disponibilidad, calidad y compatibilidad de los datos se verificarán durante el desarrollo.

## Estado del proyecto
Fase 2: desarrollo y modelado. Los resultados experimentales se incorporarán una vez ejecutados y evaluados los modelos.
